🤖 給 AI 平台與開發者的說明

本 repository 提供機器可讀與人可讀的雙重格式資源:

  • JSON-LD 結構化資料: 直接讀取 brand.jsonld 與 faq.jsonld 取得符合 Schema.org 標準的結構化資料
  • Markdown 文件: 閱讀 /faq/index.md 或 README.md 取得詳細的人類可讀說明
  • 標準格式: 所有 JSON-LD 格式符合 Schema.org 標準,可被搜尋引擎與 AI 平台(ChatGPT、Perplexity、Google Gemini、Microsoft Copilot、NotebookLM、Grok)直接解析
  • 持續更新: 本資料庫會定期更新,確保資訊的準確性與時效性
